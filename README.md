# 🚀 Space Explorer AR – Discover the Universe

<p align="center">
  <strong>An Interactive Augmented Reality Solar System Experience</strong>
</p>

## 🌌 1. Project Overview

Space Explorer AR is a web-based Augmented Reality application that brings a miniature solar system into the real world.

Using a mobile phone or computer camera, users can scan a Hiro marker to explore a 3D space environment containing planets, the Sun, a Moon, a space station, and a rocket.

The project combines 3D visualisation, animations, and interactive elements to create an engaging space exploration experience.

## 🎯 2. Project Objectives

- To develop an interactive marker-based AR application.
- To demonstrate how 3D objects can be displayed in a real-world environment.
- To explore the use of AR.js and A-Frame.
- To implement animations and interactive 3D elements.
- To create an engaging educational experience using web-based AR technology.

## 🪐 3. Features

### 3.1 Marker-Based Augmented Reality

- Uses the Hiro marker for AR detection.
- Displays the 3D solar system when the marker is detected.
- Provides a status banner to indicate marker detection.

### 3.2 3D Space Environment

The application includes:

- Sun
- Earth
- Moon
- Mars
- Jupiter
- Saturn
- Space Station
- Rocket

### 3.3 Visual Effects and Decorations

- Space-themed circular platform.
- Decorative orbital rings.
- Glowing Sun effect.
- Saturn's planetary rings.
- Decorative stars.
- Planet name labels.
- Space-themed colours and lighting.

### 3.4 Animations

- Continuous planetary rotation.
- Floating rocket animation.
- Rotating space station.
- Animated space objects.

### 3.5 Interactive Features

- Tap the Earth to change its colour.
- Tap the rocket to increase or decrease its size.

### 3.6 Marker Detection Status

The status banner changes according to marker detection.

- Green: Marker detected.
- Red: Marker lost or searching.

## ▶️ 6. How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Check that `rocket.glb` is inside the `assets` folder.
4. Run the project using a local development server.
5. Open the application in a supported web browser.
6. Allow camera access when requested.
7. Show the Hiro marker in front of the camera.
8. Explore the solar system and try the interactive features.

**Note:** Camera access generally requires HTTPS or localhost. Opening the HTML file directly may not work correctly.
